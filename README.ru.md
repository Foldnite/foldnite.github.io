# Foldnite

**Foldnite — это STEM + научные игровые механики Foldit + интерактивные миры Fortnite + квантовые вычисления.**

Мы создаём интерактивные 3D-миры, в которых игроки вместе исследуют, строят, экспериментируют и решают научные и инженерные задачи.

- **STEM** — наука, технологии, инженерия и математика.
- **Механики Foldit** — научные задачи превращаются в головоломки для совместного поиска решений.
- **Fortnite / UEFN** — интерактивные миры, миссии, социальная игра и creator-инструменты. Публикация UEFN — отдельный путь внутри Fortnite, не та же сборка, что standalone Foldnite.
- **Квантовые вычисления** — квантовые и квантово-вдохновлённые инструменты для отдельных подходящих задач. Сама игра не работает на квантовом компьютере.
- **Облачный гейминг** — удалённый GPU рендерит мир и передаёт изображение в браузер или на лёгкое устройство.
