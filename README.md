# Foldnite

**Foldnite = STEM + Foldit-inspired science + Fortnite-inspired worlds + quantum computing.**

We create interactive 3D worlds where players explore, build, experiment, and solve science and engineering missions together.

- **STEM** — science, technology, engineering, and mathematics.
- **Foldit-inspired gameplay** — scientific problems become collaborative puzzles.
- **Fortnite / UEFN** — interactive worlds, missions, social play, and creator workflows. UEFN publishing is separate from the standalone Foldnite build.
- **Quantum computing** — selected scientific tasks may use quantum or quantum-inspired tools. The game itself does not run on a quantum computer.
- **Cloud gaming** — a remote GPU renders the world and streams it to a browser or lightweight device.
